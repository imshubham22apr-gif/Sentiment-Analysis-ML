# Sentiment Analysis Bot 🤖

A simple, live, and shareable Machine Learning web application that performs sentiment analysis on any given text. Built in just 5 minutes using **Gradio** and **Hugging Face Transformers**.

## 🌟 Features
- **Instant Analysis:** Type any sentence to instantly see if it is classified as `POSITIVE` or `NEGATIVE`.
- **Pre-trained Model:** Uses Hugging Face's powerful pipeline for accurate sentiment classification without any custom training.
- **Live UI:** Provides an interactive, easy-to-use web interface using Gradio.
- **Shareable:** The app can easily be shared globally using Gradio's public URL generation.

## 🛠️ Tech Stack
- **Python** 🐍
- **[Gradio](https://gradio.app/)** - For the Web UI
- **[Transformers (Hugging Face)](https://huggingface.co/docs/transformers/index)** - For the Machine Learning Model

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imshubham22apr-gif/live-sentiment-analysis.git
   cd live-sentiment-analysis
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the app:**
   ```bash
   python app.py
   ```

4. **Access the application:**
   Open your browser and navigate to `http://127.0.0.1:7860`. You will also get a public URL if `share=True` is enabled in `app.py`.
